# 06: 宿主提供规则的即时检查与诊断提示

## What to build

宿主在打开文档时注册通用检查扩展及规则数据。编辑器在内容变化后自动更新检查结果、位置提示和范围显示，使宿主能检查自己的语法及字段目录，用户仍可保存不完整草稿。对应原需求第 4 项。

## Acceptance criteria

- [ ] 公开注册、更新和移除检查扩展或规则的契约，浏览器和 Qt 均有公开接入途径；不要求跨进程传递 JavaScript 回调。
- [ ] SDK 提供检查执行、诊断范围及提示展示；语法、字段目录、错误分类和文案由宿主或其扩展提供。
- [ ] 通过宿主测试规则验证未闭合、嵌套、跨段落、未知类型、空内容和未知字段；不能只匹配合法输入而漏掉非法构造。这些测试语法不进入 SDK 核心。
- [ ] 加载、输入、粘贴、撤销、重做及 Agent 写入后更新；异步旧结果不得覆盖新文档或新版本的诊断。
- [ ] 诊断只提示，不阻止普通保存或导出；不检查自然语言要求质量，不使用模型或 Chromium 拼写检查代替宿主校验。
- [ ] 复用通用文字范围装饰展示位置提示，检查结果与独立装饰集合互不覆盖；正文和撤销语义不受影响。
- [ ] 规则及诊断按文档实例隔离；更新、移除、切换和关闭后及时清理。
- [ ] 宿主无需每次编辑经 MCP 读取全文或调用模型；实现需验证连续输入、变化刷新和大文档下的响应性。
- [ ] 浏览器与真实 Qt 接口均演示一套外部提供的规则，包含非法输入、正确范围、修改后消失、规则移除及只读展示。

## Blocked by

- 05: 公开通用文字范围装饰。诊断的范围提示复用该能力，避免另建一套显示与位置映射机制。
