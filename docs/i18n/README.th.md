# ForaOffice

ForaOffice เป็นโครงการที่แยกมาจาก [GenOffice](https://github.com/genspark-ai/genoffice) และคงใช้ Apache-2.0 สำหรับงานโอเพนซอร์สของตน เป้าหมายคือแยกตัวแก้ไขออกจากแอปโฮสต์และเอเจนต์ในตัวเดิม เพื่อให้แอปและเอเจนต์ภายนอกนำไปผสานได้

> หน้านี้เป็นบทนำฉบับแปลแบบย่อ ดูข้อมูลฉบับเต็มและล่าสุดได้ที่ [README ภาษาอังกฤษ](../../README.md)

## ขอบเขตปัจจุบัน

ขณะนี้งานแยกส่วนครอบคลุมเฉพาะ Docs โดย SDK ระหว่างพัฒนามีอินเทอร์เฟซโฮสต์ รันไทม์แก้ไขเอกสารที่เปิดอยู่ และตัวอย่างสำหรับเบราว์เซอร์ Electron และ Qt ตัวแก้ไขอื่นยังเป็นการทำงานเดสก์ท็อปที่สืบทอดจาก GenOffice และยังแยกส่วนในลักษณะเดียวกันไม่เสร็จ การมีอินเทอร์เฟซไม่ได้ยืนยันว่ารองรับทุกโฮสต์หรือเอเจนต์ หรือผ่านการตรวจรับขั้นสุดท้ายแล้ว
