# ForaOffice

ForaOffice مشروع مشتق من [GenOffice](https://github.com/genspark-ai/genoffice)، ويواصل ترخيص عمله المفتوح المصدر بموجب Apache-2.0. يهدف إلى فصل المحررات عن التطبيق المضيف والوكيل الذكي المدمجين، لتتمكن التطبيقات والوكلاء الخارجيون من دمجها.

> هذه مقدمة مترجمة مختصرة. راجع [الوثيقة الإنجليزية](../../README.md) للحصول على المعلومات الكاملة والمحدّثة.

## النطاق الحالي

تشمل أعمال الفصل الحالية محرر Docs فقط. تتوفر حزمة SDK تطويرية مع واجهات للمضيف ووقت تشغيل للتحرير الحي وأمثلة للمتصفح وElectron وQt. المحررات الأخرى موروثة من تطبيق GenOffice المكتبي، ولم تُنجز لها عملية الفصل نفسها. هذه الواجهات لا تعني دعم كل مضيف أو وكيل أو قبول الإصدار النهائي.
