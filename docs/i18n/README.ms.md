# ForaOffice

ForaOffice ialah fork [GenOffice](https://github.com/genspark-ai/genoffice) yang mengekalkan Apache-2.0 untuk hasil sumber terbukanya. Matlamatnya ialah memisahkan editor daripada aplikasi hos dan ejen terbina dalam asal supaya aplikasi serta ejen lain boleh mengintegrasikannya.

> Ini ialah pengenalan terjemahan ringkas. Maklumat lengkap dan terkini terdapat dalam [README bahasa Inggeris](../../README.md).

## Skop semasa

Kerja pemisahan setakat ini hanya meliputi Docs. SDK pembangunan menyediakan antara muka hos, masa jalan penyuntingan langsung serta contoh untuk pelayar, Electron dan Qt. Editor lain masih merupakan pelaksanaan desktop yang diwarisi daripada GenOffice; pemisahan yang sama belum selesai. Kewujudan antara muka tidak membuktikan sokongan untuk semua hos atau ejen ataupun penerimaan pencapaian akhir.

## Integrasi dan sumbangan

[Panduan Docs SDK](../../apps/docs/sdk/README.md) · [Seni bina dan keserasian](../docs-sdk-integration.md) · [Versi dan pengedaran](../docs-sdk-releases.md)

Hos menyediakan storan, kebenaran dan perkhidmatan sistem; ejen luaran mengurus model, perbualan dan tugas. Alat berasaskan fail dan masa jalan editor yang terbuka ialah antara muka berbeza. Ciri desktop tidak disertakan secara automatik dalam SDK.
