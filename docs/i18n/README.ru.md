# ForaOffice

ForaOffice — форк [GenOffice](https://github.com/genspark-ai/genoffice), сохраняющий Apache-2.0 для своей работы с открытым исходным кодом. Цель — отделить редакторы от исходного приложения-хоста и встроенного агента, чтобы их могли интегрировать другие приложения и агенты.

> Это краткое переведённое введение. Полная и актуальная информация приведена в [английском README](../../README.md).

## Текущий охват

Выполненная работа по отделению пока касается только Docs. Разрабатываемый SDK предоставляет интерфейсы хоста, среду редактирования открытого документа и примеры для браузера, Electron и Qt. Остальные редакторы остаются унаследованными настольными реализациями GenOffice; аналогичное отделение для них не завершено. Наличие интерфейсов не доказывает поддержку любого хоста или агента и не означает приёмку итогового этапа.

## Интеграция и участие

[Руководство Docs SDK](../../apps/docs/sdk/README.md) · [Архитектура и совместимость](../docs-sdk-integration.md) · [Версии и распространение](../docs-sdk-releases.md)

Хост предоставляет хранение, разрешения и системные службы; внешний агент управляет моделью, диалогом и задачами. Файловые инструменты и среда открытого редактора — разные интерфейсы. Возможности настольного приложения не включаются в SDK автоматически.
