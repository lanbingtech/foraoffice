# ForaOffice

ForaOffice הוא פיצול של [GenOffice](https://github.com/genspark-ai/genoffice), השומר על רישיון Apache-2.0 לעבודתו בקוד פתוח. המטרה היא להפריד את העורכים מהיישום המארח ומהסוכן המובנה המקוריים, כדי שיישומים וסוכנים חיצוניים יוכלו לשלב אותם.

> זהו מבוא מתורגם ומקוצר. למידע מלא ועדכני יש לעיין ב־[README באנגלית](../../README.md).

## היקף נוכחי

עבודת ההפרדה הנוכחית כוללת את Docs בלבד. ערכת ה־SDK בפיתוח מספקת ממשקי מארח, סביבת עריכה חיה ודוגמאות לדפדפן, ל־Electron ול־Qt. העורכים האחרים הם מימושי שולחן העבודה שהתקבלו מ־GenOffice, והפרדתם המקבילה טרם הושלמה. קיומם של ממשקים אינו הוכחה לתמיכה בכל מארח וסוכן או לאישור אבן דרך סופית.
